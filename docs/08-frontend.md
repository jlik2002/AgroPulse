# Интерфейс

React 18, TypeScript, Vite, Tailwind, Radix UI. Карта — Leaflet с leaflet-geoman, графики — ECharts. Состояние сервера — TanStack Query.

Типы ответов API описаны вручную в `src/api/types.ts`, а не генерируются: набор эндпоинтов небольшой, а лишний шаг генерации усложнил бы запуск по README.

## Экраны

| Путь | Экран |
|---|---|
| `/` | выбор или создание проекта |
| `/p/:id/fields` | карта, контуры, период анализа |
| `/p/:id/farms` | реестр приоритетной поддержки |
| `/p/:id/farm/:farmId` | карточка хозяйства |
| `/p/:id/processing` | прогресс по стадиям |
| `/p/:id/summary` | сводка и очередь на осмотр |
| `/p/:id/field/:fieldId` | поле: обзор, снимки, динамика, данные |
| `/p/:id/field/:fieldId/forecast` | прогноз на 14 дней |
| `/p/:id/data` | таблица наблюдений |
| `/p/:id/reports` | сборка и предпросмотр PDF |

Проект и его поля читаются один раз в оболочке: номер поля и период нужны всем экранам сразу.

## Правила отображения

**Цвет — дополнительный сигнал, не единственный.** Рядом со статусом всегда стоит текст.

**Происхождение значения видно всегда.** Наблюдаемое, восстановленное и прогноз различаются визуально на графике и в таблице. Это продуктовый принцип, а не оформление.

**Отсутствие данных не выглядит как хорошая новость.** Поле без балла показывается с причиной, а не с нулём. Хозяйство без заключения выносится отдельным списком, а не в конец очереди.

**Достоверность стоит рядом с баллом.** Порознь они позволяют прочитать «низкая потребность» там, где просто нет снимков.

## Обязательные поля карточки

При создании поля обязательны хозяйство и культура текущего сезона.

Культура — потому что норма строится по прошлым сезонам того же поля, где культура могла быть другой: без неё расхождение с нормой неотличимо от севооборота.

Хозяйство — потому что поле без владельца не попадает ни в одну строку реестра. Хозяйство заводится прямо в карточке поля пунктом «Новое хозяйство…»: отдельный экран посреди рисования контура заставил бы бросить работу на полпути.

Запуск анализа блокируется, если у выбранного поля нет культуры.

## Прогресс

Пока идёт расчёт, страница обработки слушает SSE и показывает стадии по каждому полю отдельно. Готовое поле открывается, не дожидаясь остальных.

Периодического опроса на готовых экранах нет: посчитанная сводка меняется только по действию пользователя.

## Разработка

Vite проксирует `/api` на поднятый Compose'ом бэкенд, адрес задаётся `VITE_API_PROXY`. В собранный образ адрес не зашит: `/api` проксирует nginx внутри контейнера `web`.

Проверка типов — `npx tsc -b`. Команда `tsc --noEmit` в этом проекте не проверяет ничего: корневой `tsconfig.json` содержит `files: []` и ссылается на конфигурации через `references`.
