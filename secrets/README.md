# Секреты

Каталог для локальных секретов. В репозиторий не коммитится (см. `.gitignore`).

Ожидаемые файлы:

- `gee-service-account.json` — ключ сервис-аккаунта Google Earth Engine.
  Как получить: в Google Cloud Console создать сервис-аккаунт, зарегистрировать
  его в Earth Engine, выпустить JSON-ключ и положить сюда под этим именем.

Без этого файла сервис поднимается, но обработка любого поля падает на сборе
спутниковых данных: цепочка источников состоит из одного Earth Engine. Реализация
поверх STAC существует (`providers/satellite_stac.py`), но в цепочку сознательно
не включена. Пошаговая настройка доступа — в корневом README, шаг 3.

В Kubernetes тот же файл подключается через Secret по пути `/run/secrets`.
