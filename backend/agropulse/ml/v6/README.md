### Единственная правка: `scene_features`

Добавлен необязательный параметр `context`. При `context=None` поведение
архивного файла воспроизводится в точности, поэтому старые запуски не меняются.

Правка понадобилась потому, что `scene_features` заполняет общую матрицу
ожидаемых значений `smooth` только в ячейках переданных строк, а читает из неё
ожидания **других** полей той же съёмки. При обучении туда приходил весь кадр,
и матрица была полной. Если при предсказании передать только целевые строки,
матрица окажется почти пустой, признаки съёмки выродятся в пропуски, и модель
молча начнёт считать другое: расхождение с эталоном получалось 0.066 при
среднем уровне ошибки самой модели 0.065. По результату такое не диагностируется —
числа остаются правдоподобными. `context` разделяет два множества строк:
матрица заполняется по всему кадру, признаки считаются для целевых строк.

Заменена также управляющая часть `ndvi_v6.py`: она обучала и предсказывала
одним проходом. Обучение в сервисе не нужно — модель обучена один раз,
её артефакты лежат в `artifacts/`. Роль управляющей части исполняет
`pipeline.py`, в нём только предсказание.

## Как устроена модель

Опора — линейная интерполяция между ближайшими видимыми наблюдениями,
приведённая к шкале конкретного прибора. CatBoost предсказывает не NDVI,
а **поправку к опоре**: деревья плохо выражают тождество `y ≈ x`, поэтому
арифметику делает опора, а обучение достаётся остатку.

`primary_ndvi` склеен из трёх приборов (Sentinel-2, Landsat, MODIS) с разными
шкалами. Поэтому предсказание считается трижды — по одному разу в шкале
каждого прибора — и сворачивается вероятностями отдельного классификатора,
который по признакам даты угадывает, каким прибором снята целевая точка.
Гармонизация приборов — крупнейший одиночный выигрыш модели.

Признаки: геометрия пропуска, климатология поля без целевого года, погода,
эффект дня (общий для всех полей остаток съёмки — ловит дымку и тонкую
облачность), преобразования отдельной съёмки по другим полям.

## Ограничения

Модель **транcдуктивная**: она обучается на видимых точках тех же полей,
для которых предсказывает, и часть её признаков — межполевые (доноры,
эффект дня). Из этого следуют два практических ограничения:

1. Обучение требует опорного набора (`ML_V6_REFERENCE_DATASET`), а не только
   ряда одного поля.
2. Для поля, которого не было в обучении, категория `field_category`
   неизвестна модели, а межполевые признаки считаются по датам опорного
   набора. Если даты поля не пересекаются с ним, эти признаки пусты.

Прогноза на будущее V6 не делает вовсе: она восстанавливает точку между
наблюдениями и требует соседей с обеих сторон.
