Методика, источники и ограничения

Вегетационный индекс NDVI рассчитан по снимкам Sentinel-2 (коллекция {{ methodology.collection }}) как среднее по пригодным пикселям внутри контура поля. Облачность отфильтрована по маске классов сцены и вероятностной маске облаков. Погодные данные: {{ quality.weather_source }}. Ожидаемая динамика построена по собственной истории поля за предыдущие сезоны; отклонение измерено в единицах стандартного отклонения нормы.

Сервис даёт первичную дистанционную оценку и не заменяет обследование поля. Указанные причины отклонений являются гипотезами. Сервис не ставит диагноз по снимку, не измеряет влажность почвы напрямую и не прогнозирует урожайность. {% if summary_text %}Пояснительный текст сформирован языковой моделью на основе рассчитанных значений; все числа и даты в нём автоматически сверены с исходными данными.{% endif %}
